# Tetris world model

A 2M-parameter world model of NES Tetris running in the browser: every frame is generated by the model
from the frames before it and your buttons; no emulator runs. It starts at the very beginning of a
level-0 game. Arrows move and drop, X / Z rotate, Enter is Start.

Needs WebGPU (Chrome or Edge on desktop); elsewhere it falls back to WebAssembly, which is slow.
Built with onnxruntime-web from the step-90,607 checkpoint. No game ROM is included or used here.
